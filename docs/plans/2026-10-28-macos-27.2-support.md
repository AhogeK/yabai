# Plan: macOS 27.2 support (Dock 2571.1.32.402)

Date: 2026-10-28 · Status: completed · Versions: 7.2.6 → 7.2.13 (OSAX 2.1.34 → 2.1.41)

## Objective

Restore the scripting addition on macOS 27.2 after Dock was rebuilt, without ever letting a
misidentified pattern crash Dock again. The old release scanned a fixed window past the new
`__TEXT` end, read a protected page, and put Dock into a launch crash loop.

## Implementation Steps

1. **Stop the crash loop** — clamp every `hex_find_seq` scan to the `__TEXT` end; refuse to scan
   when the text end or `scan_limit` is unknown. Add `verify_dock_build()` with an explicit
   (os_version, Dock build) whitelist for 27.x. Unknown build → SA disables itself.
2. **27.2 profile** — Dock build lock; decode Spaces singleton from the factory slot
   (`0x329be0`); create helper `0x20ce00`; empty-array singleton slot `0x2ef0d8`.
3. **Restore abilities** — create (unique UUID identity, display landing check), focus (pure SLS
   view switch), destroy (`CGSSpaceDestroy`), cross-display move
   (`CGSMoveManagedSpaceToDisplayIndex`), same-display reorder (`SLSTransaction*` + commit).
4. **Handshake** — declare only implemented abilities; `OSAX_ATTRIB_REQUIRED` = ADD\|REM\|MOV;
   ADD is reported only when helper + Swift bridge + singleton all resolve.
5. **Harden** — segment-range validation for every fixed-address read (`__TEXT` / `__DATA` /
   `__DATA_CONST` / `__AUTH_CONST`), null guards on every disabled Dock pointer, `@autoreleasepool`
   around the focus array, post-action verification logs.
6. **Verify** — build 0 warnings, `make -C tests` 2/2, then a live integration run on macOS 27.2.

## Lessons

- **Pattern hit ≠ function identity.** The 27.2 `remove_space` pattern matched `0x12dbcc`, a
  function that only saved four argument registers — not `removeSpace`. Always confirm prologue
  and call shape.
- **Segment checks must include `__DATA_CONST`.** `__swiftEmptyArrayStorage` lives in a
  `__DATA_CONST` GOT slot; a `__DATA`-only check silently disabled create.
- **Fail closed on unknown builds.** A wrong pattern is a Dock crash loop; disabling the SA is
  recoverable.
- **Verify the full surface.** create working did not imply move/reorder/destroy; each ability
  was exercised against a temporary empty space and cleaned up.
