## 执行流程

### 阶段 1: 读取现有记忆文件

读取 `memory-bank/` 全部文件，确认当前状态。

### 阶段 2: 识别需更新内容

按 AGENTS.md R2 的触发映射表，识别本次会话产生的新信息：

**yabai 特有的记录重点**：
- 发现的私有 API 行为（如 SkyLight 函数的实际参数语义）
- 已知崩溃场景或触发条件
- macOS 版本兼容性问题
- scripting-addition 注入的边界条件
- IPC 协议的隐性约定

**时间获取**: `date "+%Y-%m-%d"`

### 阶段 3: 写入并检查行数

按 AGENTS.md R12 检查行数，超限立即修剪。

### 阶段 4: 输出摘要

```
=== 记忆保存 ===

已更新:
- [文件名]: [更新内容摘要]

保留未更新:
- [文件名]: [原因]
```

## 触发场景

- 解决了一个 macOS 版本兼容问题
- 确认了某个私有 API 的实际行为
- 完成了一个功能模块的实现
- 切换工作焦点前
- 用户明确要求保存

## 禁止事项

- **不假设**：必须先读取现有内容再追加
- **不遗漏日期**：每条记录必须包含 `[YYYY-MM-DD]`
- **不冗余**：只记录新信息，不重复已有内容
- **不猜测 API 行为**：未验证的行为必须标记 `[UNVERIFIED]`
